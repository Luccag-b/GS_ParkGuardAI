# PARKGUARD AI
Mobilidade inteligente, segura e inclusiva. React 18 + React Router + CSS puro, dados mockados (sem backend).

    npm install && npm run dev

Pastas: `components`, `pages`, `styles`, `data`, `utils`, `context`.
Integrações futuras: troque `src/data/mock.js` por chamadas a APIs (mapas, geolocalização, estacionamentos, IA de validação, reservas) e `MapView` por um provedor real de mapas.
