# PARKGUARD AI — React prototype

Run locally: `npm install` then `npm run dev`.

Features: login and registration flow, accessibility preferences captured at signup and used in the dashboard, parking search/filter, road reports, profile, and an interactive OpenStreetMap with address suggestions from ViaCEP for the current city/UF, address geocoding through Nominatim, 24 illustrative street-parking/garage/accessibility markers within the 1 km destination radius alongside parking facilities and mapped accessibility details from Overpass, browser geolocation, and driving routes via OSRM.

**Prototype limits:** accounts and preferences are stored only in the browser; this is not production-grade authentication and does not use a server. Do not use real or sensitive passwords. ViaCEP is a free third-party CEP service, not an official Correios API; address suggestions require a city and state inferred from the current map region. The 24 markers are illustrative positions generated around the destination; they do not represent real streets, parking facilities, accessible infrastructure, or live availability. OpenStreetMap may show mapped parking and accessibility details, but tags may be incomplete and it does not provide live free-space availability. The dashboard's sample vacancy counts are not live data, and there are no actual reservations, AI vision, or camera/sensor integration. The browser asks for location permission when a route is searched. ViaCEP, Nominatim, the Overpass API, and the OSRM demo service are subject to service availability and usage limits. Validate accessibility information with people with disabilities before real-world use.

For production or high-traffic use, connect appropriately hosted geocoding and routing services and a trusted source of real-time parking availability.
